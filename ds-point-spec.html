1포인트 지급 카드조건
조회 기준일까지 지급된 DS포인트 전체 누적 합계.
계산식
최초 지급 포인트 = SUM(포인트금액)
　WHERE 작성자=이메일 AND 이벤트=이벤트
　AND 타입=적립 AND 지급일자 ≤ 조회기준일
회수 포인트 = SUM(포인트금액)
　WHERE 작성자=이메일 AND 이벤트=이벤트
　AND 타입=차감 AND 차감일자 ≤ 조회기준일
최종 지급 포인트 = 최초 - 회수
회수: 직접 환수 + 주문 취소 환수 포함. 환수 포함/제외 토글로 전환.
1-1환수 포함/제외 토글추가
지급 카드 하단 토글. 전환 시 모든 KPI의 기준값이 변경됨.
동작
환수 포함: 최초 지급 포인트 기준
환수 제외: 최종 지급 포인트 기준
→ 사용률, 소멸률, 잔여 비율 재계산
2포인트 사용 카드조건
조회 기준일까지 누적 사용 현황.
계산식
실 사용 포인트 = SUM(사용금액)
　WHERE 작성자=이메일 AND 이벤트=이벤트
　AND 사용일자 ≤ 조회기준일
　AND 주문상태 = 정상(취소/환불 제외)
사용률 = 최종 지급금액 중 실제 사용된 금액의 비율 (실사용금액 ÷ 최종지급금액)
사용건수비율 = 지급 건수 중 실제 사용이 발생한 건수의 비율 (사용건수 ÷ 지급건수)
3포인트 소멸 카드조건
조회 기준일까지 누적 소멸 현황. 전액·부분 소멸 구분.
계산식
소멸 포인트 = SUM(포인트금액)
　WHERE 작성자=이메일 AND 이벤트=이벤트
　AND 타입=소멸 AND 소멸일자 ≤ 기준일
전액 소멸: 한 번도 사용하지 않고 유효기간이 만료된 건
부분 소멸: 일부만 사용하고 남은 잔액이 유효기간 만료로 소멸된 건
소멸률 = 최종 지급 포인트 중 소멸된 비율
확인필요 타입 컬럼에 "소멸" 값 존재 여부 개발팀 확인 필요.
4잔여 현황 카드조건
기준일 기준 미사용·미소멸 포인트 추정.
계산식
잔여 포인트 = 최종지급 - 실사용 - 소멸포인트
잔여 비율 = 최종 지급 포인트 중 아직 사용·소멸되지 않은 비율
소멸 예정 = 기준일 기준 3개월 내 만료 예정 포인트
확인필요 소멸 예정 계산 시 지급일+3개월 기준 유효기간 만료일 조회 필요.
